# 拾光 1.4.0

一颗球，两种选择。休息、回来或收工，让两只笑着对视的小半球陪你决定。

## 交互与计时

- 工作中单击球体，右上橙红色「我先溜会」暂停计时，左下蓝色「我要下班」签退。
- 暂停时单击球体，左上绿色「我回来了」继续工作，右下蓝色「我要下班」直接签退；休息时间不会补算。
- 操作在球体原地展开，日历中使用相同的半球选项，支持中英文。中间小叉、Esc 或点击其他窗口可取消桌面选择。
- 每日累计最多 `24:00:00`。补录、实时计时、重启恢复与显示统一遵守上限，跨午夜继续累计下一天；周月汇总可超过 24 小时。
- 超限补录会实时提示并禁用保存。旧版超限日期归一到 24 小时，保留日期及其他记录。
