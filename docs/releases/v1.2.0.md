# 拾光 1.2.0

一颗住在桌面上的工作球，让认真度过的时间，长成日历上的一圈绿意。

本次提供正式安装版，并修复 Windows 登录自启动误报失败的问题。作者：**Hoshi Takyobu**。

## 本次更新

- 统一启动项的写入和验证标识，支持中文及含空格路径，自动清理旧启动项。
- 识别 Windows 启动应用中的暂停状态，手动重新开启可恢复启动。
- 安装向导支持选择位置，创建桌面和开始菜单快捷方式，可通过 Windows 卸载。
- 设置页可查看程序位置；版本、作者和 Windows 文件属性署名保持一致。
- 提供 MIT 许可、源码包、发布文档与 SHA-256 校验。

## 下载选择

| 文件 | 用途 |
| --- | --- |
| `Shiguang-1.2.0-Setup-x64.exe` | **推荐**。日常安装使用。 |
| `Shiguang-1.2.0-Portable-x64.exe` | 免安装试用，放在固定目录运行。 |
| `Shiguang-1.2.0-Source.zip` | 完整项目源码，不包含依赖和个人工时。 |
| `SHA256SUMS.txt` | 下载文件的 SHA-256 校验值。 |

支持 Windows 10 / 11 x64，无需额外安装 Node.js。当前包未进行数字签名，Windows 可能显示未知发布者或 SmartScreen 提示，请核对来源及校验值。

## 从旧版本升级

1. 右键旧工作球或托盘图标，选择“退出”。
2. 运行 Setup 安装包；原工时和设置会继续使用。
3. 如果旧版曾提示自启动失败，在“设置 → 常规”重新开启一次。

默认程序位置为 `%LOCALAPPDATA%\Programs\shiguang-work-orb`。记录仍独立保存在 `%APPDATA%\拾光`，或之前选择的数据目录。正常卸载保留这些记录。

## 校验下载

```powershell
Get-FileHash .\Shiguang-1.2.0-Setup-x64.exe -Algorithm SHA256
```

将结果与 `SHA256SUMS.txt` 对照。使用说明和计时规则见仓库 README。
