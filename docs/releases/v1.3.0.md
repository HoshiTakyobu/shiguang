# 拾光 1.3.0

一颗会在桌面边缘偷看的工作球，陪你工作，也陪你歇一会儿。

## 体验

- 拖到屏幕左右边缘，会缩成 80 像素的小球，仅露出四分之一，目光跟随鼠标。点击或拖出即可恢复。
- 工作中单击打开选择气泡：临时离开会暂停计时并变成暖橙红色，也可直接下班。暂停可跨午夜和重启保留。
- 设置中可即时切换简体中文 / English，并选择一周从哪天开始，日历和周工时同步调整。
- Windows 全局单实例保护，同一台电脑只运行一个正式拾光应用。
- 安装向导可选语言和安装位置。卸载软件完成后，可选择保留或删除当前数据，默认保留；升级和静默卸载保留记录。

## 下载

| 文件 | 用途 |
| --- | --- |
| `Shiguang-1.3.0-Setup-x64.exe` | 推荐，支持自选目录和系统卸载的安装版。 |
| `Shiguang-1.3.0-Portable-x64.exe` | 放到固定目录运行的免安装版。 |
| `Shiguang-1.3.0-Source.zip` | 源码、文档、截图、测试与发布流程。 |
| `SHA256SUMS.txt` | 上述文件的 SHA-256 校验值。 |

Windows 10 / 11 x64，无需 Node.js。默认工时目录 `%APPDATA%\拾光` 与程序目录分开；旧记录和设置自动兼容。

作者 **Hoshi Takyobu**，MIT 开源。当前二进制未做数字签名，Windows 可能显示未知发布者提示。

升级前退出旧版，然后运行安装包；换盘重装时请在卸载询问中保留数据。暂停期间不累计，工作状态下的睡眠和锁屏时间仍计入工时。

```powershell
Get-FileHash .\Shiguang-1.3.0-Setup-x64.exe -Algorithm SHA256
```

将结果与 `SHA256SUMS.txt` 对照。
