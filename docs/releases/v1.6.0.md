# 拾光 1.6.0

按月看见积攒的工时，在达标时收到一场礼花，也能从手机随时查看。

## 月度目标与庆祝

- 日历显示所选月份的累计工时、目标进度、剩余时间和预计月收入。月累计只统计自然月，跨月周工时不会混入。
- 「设置 → 月度目标」可自定义基础档，并添加或删除多个 Bonus 档，分别设置工时门槛和月收入。默认基础 160 小时 / CNY 800，另有一档 Bonus 200 小时 / CNY 1600；金额为当月总收入，不叠加。工时门槛须逐档增加，月收入不能递减。
- 日历与手机页面显示所有启用档位，进度、剩余时间和预计收入指向下一未达成档，全部达成后显示最高档。
- Bonus 可以整体关闭并保留各档设置，也可删除全部 Bonus，只使用基础目标。兼容已有单 Bonus 设置和庆祝记录。
- 达标后工时仍继续累计。每月每档自动庆祝一次，一次跨过多档只庆祝最高已达成档；跨月重新计算，补录和退出后补计也会更新目标进度。
- 庆祝窗口采用本次提供的方正粗圆简体，包含礼花、月度徽章、当前累计和收入卡片。可预览、重放礼花或关闭自动庆祝。

## 手机跨网查看

- 「设置 → 手机查看」可连接自己的 HTTPS 服务。电脑主动同步，手机用独立查看密码登录，不需要处于同一局域网。
- 电脑约每 5 秒更新状态，网页每秒显示计时。断网或退出后最多约 20 秒显示离线和最后同步信息。
- 网页只读查看今日工时、月累计、工作状态和目标；不上传本地明细、文件路径或桌面控制接口。连接密钥使用 Windows 凭据加密。
- 部署代码与说明见 [云端服务](../../cloud/README.md)。

## 退出与悬浮球修复

- 正常退出时可选继续计时、停止计时或取消；暂停状态可选开始计时或保持暂停。下班状态直接退出，已有工时保留。
- 继续计时会完全关闭程序，下次启动补计退出期间时间，包括关机时间。程序运行中遇到 Windows 关机仍自动下班；异常退出止于最后保存点。
- 悬浮球不占任务栏与 Alt+Tab。贴边横向露出约 40 像素，高度不变，并扩大眼睛和点击范围。
- 修复窗口销毁后屏幕事件导致的异常，以及下班状态下退出请求重入。
