# 拾光 1.5.0

用自己的快捷键开始工作、休息或收工，也能看见每天的时间明细。

## 全局快捷键

- 「设置」新增独立「快捷键」页，可配置上班、休息、继续工作、下班和显示／隐藏工作球五个动作。
- 点击录入框并按下组合键，保存后即刻生效；清除后保存可禁用。默认全部未设置，在其他应用中也能使用已保存的快捷键。
- 保存时检查动作间的重复绑定与 Windows 注册冲突；失败保留原绑定，重启应用后不可用的组合会显示提示。系统无法告知具体哪个应用占用了组合键。

## 每日记录

- 点击日历日期，查看上班、休息、继续工作和下班的具体时间，以及当日的在岗与休息时段。
- 跨午夜时段按本机日期拆分，今日进行中的时段实时更新。
- 补录和总时长修正保留操作时间及修改前后的累计，不改写实际在岗时段。
- 每日记录和新增提示支持简体中文与 English。

## 关机与恢复

- Windows 关机、重启或注销时，工作和暂停中的会话都会自动下班，并同步保存。
- 异常中断后，工作在最后成功保存的计时点结束，重新启动不再把关机或未运行期间计入工时。最近尚未保存的时间可能丢失，恢复后需手动签到。
- 正常退出仍会签退工作中的会话，并保留暂停状态。锁屏和睡眠继续遵循原有规则：工作中计时，休息中不计时。

升级保留旧版累计工时，但无法还原从未记录的上下班节点。手动补录会留下调整记录，不会补造在岗时段，因此累计可能与明细时段相加结果不同。导出备份包含已有明细，并在导出时间结束副本中的未完成时段；当前工作球继续原有状态。
