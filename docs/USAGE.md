# 拾光使用手册

一颗可以拖动、始终置顶的工作球，陪你记录每天的工作时间。

## 使用

推荐从 [GitHub Releases](https://github.com/HoshiTakyobu/shiguang/releases/latest) 下载 `Shiguang-版本号-Setup-x64.exe`，跟随向导选择目录并安装。也可直接运行 `Shiguang-版本号-Portable-x64.exe` 免安装使用，首次启动需要短暂解压。无需安装 Node.js；系统要求 Windows 10 / 11，x64。

安装版默认位于 `%LOCALAPPDATA%\Programs\shiguang-work-orb`，可以在安装向导中选择其他磁盘和目录。快捷方式会出现在桌面和开始菜单；卸载请使用 Windows 的“已安装的应用”。升级保留工时及设置；卸载完成后会询问是否删除当前数据，默认保留。程序位置可从“设置 → 高级”查看。

- **单击蓝色圆球任意位置**：签到并开始累计。工作中单击会弹出气泡，可选择「临时离开」暂停或「下班啦」签退；暂停时可选择「继续工作」或下班。
- **双击圆球**：打开本月日历；双击不会顺带签到或签退。
- **按住圆球拖动**：调整位置，重启后记住位置。
- **拖到屏幕左侧或右侧**：球体缩到 80 像素直径，只露出四分之一，眼睛跟随鼠标。单击探头球只会展开，不会改变工作状态；也可拖出边缘。贴边位置在重启后保留。
- **右键圆球**：打开菜单，可隐藏工作球、恢复到主屏、查看数据位置或退出。
- **系统托盘**：单击图标显示工作球，双击打开日历，右键打开菜单。
- **日历左上角箭头**：翻看月份，也支持键盘左右方向键。`Esc` 关闭日历。
- **点击某个日期**：打开该日的补录窗口。工具栏也有「补录工时」入口；悬停日期或周工时可查看精确时长。
- **日历右上角「设置」**：打开独立设置窗口，也可以从工作球右键菜单进入。

为区分单击与双击，单击会等待 Windows 设置的双击判定时间，通常约半秒。

## 计时规则

- 球上的 `HH:MM:SS` 是**当天累计工时**。签到后逐秒更新，签退暂停；再次签到接着累计。
- 每天按本机时区的 **00:00 到次日 00:00** 统计，跨午夜自动拆分。
- **零工时不显示圆圈**。开始积累后，圆环从 **12 点钟方向顺时针**增长，默认工作 8 小时闭合。时间越长，颜色越接近清新绿色；较短的弧更深。
- 圆环目标可在设置中修改；超过目标后圆环保持闭合，工时继续完整记录。
- 默认每周以周一开始，也可在设置中从七天里任选起始日。左侧是**这一行连续七天的总工时**，包含月初、月末跨月日期。周末颜色始终对应实际的周六、周日。月累计仅统计正在查看的月份。
- 小时汇总显示到小数点后一位；详细记录和计时器保留到秒。
- 关闭或最小化日历，工作球继续计时。
- **工作状态下，锁屏、睡眠时间也计入工时**。「临时离开」停止累计，显示暖橙红色的「已暂停」，直到选择继续工作；暂停跨午夜或重启都不会增加工时。
- 正常退出应用会自动保存，工作中的会话签退，暂停状态保留。异常中断后重启，会从上次存档的状态恢复；如果当时仍在工作，中断期间也会计入工时。

## 本地数据

运行时不需要联网。字体已随应用内置，不依赖在线字体服务。

工时默认存于 Windows 的 `%APPDATA%/拾光/worklog.json`，也可右键工作球选择「打开数据文件夹」。活跃计时每 15 秒保存一次，签到、签退、补录、休眠及退出时立即保存；另保留一份最近的有效备份 `worklog.json.bak`。

在「设置 → 高级」中可选择新数据文件夹。已有记录会复制到新位置并立即切换，原文件保留。新文件夹不能已有拾光记录，以免覆盖历史。迁移后若数据磁盘不可用，启动时会提示连接磁盘，不会创建空历史覆盖旧记录。也可以用「导出备份」另存所有日期的工时。

偏好设置始终存于 `%APPDATA%/拾光/settings.json`，其中记录数据文件夹的位置。

## 补录与设置

- **补充时长**：在该日现有工时上增加输入的时长。
- **修正总时长**：把该日累计调整为输入值；设置为零可清除该日的进度环。
- 补录可精确到秒，只能选择今天或过去的日期，保存后的当日累计不能超过 24 小时。今日正在计时时，补录不会停止计时。
- **常规**：开机自启动、简体中文／English、每周起始日、薄荷晴空／雾蓝石墨／松石暖砂三套主题。
- **工时**：设置圆环转满一圈对应的时长，范围为 1 分钟至 24 小时。修改后所有月份按新目标显示，不改变原工时。
- **高级**：查看程序安装位置、迁移数据文件夹、打开文件夹、导出备份。

新安装默认启用 Windows 登录自启动，可随时在设置中关闭，已有设置会保留。自动启动只显示工作球，不会自动签到。安装版的启动项指向安装目录的程序；免安装版指向原始 EXE，不使用临时解压目录。移动免安装程序后，手动运行一次即可更新启动路径。开发模式与界面测试不会更改正式启动项；专门的启动项测试使用独立注册表项并在结束时清理。

若 Windows 曾暂停此项，请在常规设置中关闭后重新开启，或在 Windows“启动应用”中恢复。若保留免安装版与安装版，请固定使用其中一份，避免交替运行时来回改写启动路径。同一台电脑只允许一个正式应用实例；同账户重复打开会回到已有应用，另一个 Windows 会话中的重复启动会直接退出。

## 卸载与数据选择

普通卸载会先移除程序、快捷方式和启动项，然后询问是否删除当前工时记录、设置和缓存，默认选择“否”。选择“是”会删除默认数据目录，以及当前自定义数据目录中的 `worklog.json`、`.bak` 和 `.tmp`，不会删除自定义目录本身、其他文件、导出的备份或之前迁移留下的旧副本。删除无法撤销。

覆盖升级和静默卸载不会询问或删除工时。若你打算换盘重装，请保留数据，再在安装向导选择新的程序目录。

若主记录损坏，应用尝试读取备份；两份均损坏时会提示错误，避免悄悄清空历史。移动免安装程序的位置不会影响记录。

仓库 [界面预览](images/calendar-preview.png) 使用隔离测试目录中的**示例工时**，不会写入真实工时。

## 换电脑与恢复备份

1. 在原电脑的“设置 → 高级”导出工时备份，退出拾光。
2. 在新电脑安装并运行一次拾光，确认数据目录，然后退出。
3. 将新电脑现有的 `worklog.json` 和 `worklog.json.bak` 另存备份，再将导出的 JSON 复制为数据目录下的 `worklog.json`；同步复制一份为 `worklog.json.bak`。
4. 重启拾光，检查日期和累计时长。导出的备份不包含正在计时的签到状态，恢复后从签退状态开始。

不要直接跨电脑复制旧的 `settings.json`，其中的数据目录可能是原电脑专用路径。目标、主题和开机启动可在新电脑重新设置。当前没有自动云同步或界面内导入功能。

## 开发

```powershell
npm ci
npm start
npm test
npm run test:startup
npm run test:system
npm run test:ui
npm run check:docs
npm run dist
npm run release:prepare
```

- `src/main.cjs`：桌面窗口、托盘、进程生命周期与 IPC。
- `src/clock.cjs`：按本机日期拆分时间与累计工时。
- `src/store.cjs`：本地原子写入和备份恢复。
- `src/renderer/`：悬浮球、月历和界面样式。
- `tests/`：计时、存档和真实 Electron 窗口的集成检查。

使用 Electron 与原生 HTML / CSS / JavaScript。窗口启用了上下文隔离、渲染器沙箱和有限的预加载接口；不加载外部页面。

辅助文字使用内置的 Noto Sans SC；月份和日期使用 Nunito，品牌与主标题保留站酷快乐体。字体均采用 SIL Open Font License，许可证随 `assets` 分发。Noto Sans SC 来自 [Google Fonts 的字体仓库](https://github.com/google/fonts/tree/main/ofl/notosanssc)。
