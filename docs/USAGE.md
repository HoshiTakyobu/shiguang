# 拾光使用手册

一颗可以拖动、始终置顶的工作球，陪你记录每天的工作时间。

## 使用

推荐从 [GitHub Releases](https://github.com/HoshiTakyobu/shiguang/releases/latest) 下载 `Shiguang-版本号-Setup-x64.exe`，跟随向导选择目录并安装。也可直接运行 `Shiguang-版本号-Portable-x64.exe` 免安装使用，首次启动需要短暂解压。无需安装 Node.js；系统要求 Windows 10 / 11，x64。

安装版默认位于 `%LOCALAPPDATA%\Programs\shiguang-work-orb`，可以在安装向导中选择其他磁盘和目录。快捷方式会出现在桌面和开始菜单；卸载请使用 Windows 的“已安装的应用”。升级保留工时及设置；卸载完成后会询问是否删除当前数据，默认保留。程序位置可从“设置 → 高级”查看。

- **单击蓝色圆球任意位置**：签到并开始累计。工作中单击会斜分成两半，右上橙红色「我先溜会」暂停，左下蓝色「我要下班」签退；暂停时单击则是左上绿色「我回来了」继续累计，右下蓝色「我要下班」直接签退。两只半球带有笑着对视的表情。
- **收起半球选项**：点击中间小叉、按 `Esc` 或点击其他窗口，原工作状态保持不变。日历的「选择操作」也提供同样的两种选择。
- **双击圆球**：打开本月日历；双击不会顺带签到或签退。
- **按住圆球拖动**：调整位置，重启后记住位置。
- **拖到屏幕左侧或右侧**：球体变为宽 104、高 80 像素的探头，露出约 40 像素，眼睛跟随鼠标。单击探头球只会展开，不会改变工作状态；也可拖出边缘。贴边位置在重启后保留，悬浮球不占任务栏按钮。
- **右键圆球**：打开菜单，可隐藏工作球、恢复到主屏、查看数据位置或退出。
- **系统托盘**：单击图标显示工作球，双击打开日历，右键打开菜单。
- **日历左上角箭头**：翻看月份，也支持键盘左右方向键。`Esc` 关闭日历。
- **点击某个日期**：打开「每日记录」，查看当日累计、在岗与休息时段、上班和下班等关键节点。点击记录内的「补录工时」可调整累计；日历工具栏也有直接补录入口。
- **日历右上角「设置」**：打开独立设置窗口，也可以从工作球右键菜单进入。

为区分单击与双击，单击会等待 Windows 设置的双击判定时间，通常约半秒。

## 计时规则

- 球上的 `HH:MM:SS` 是**当天累计工时**。签到后逐秒更新，签退暂停；再次签到接着累计。
- 每天按本机时区的 **00:00 到次日 00:00** 统计，跨午夜自动拆分。
- **零工时不显示圆圈**。开始积累后，圆环从 **12 点钟方向顺时针**增长，默认工作 8 小时闭合。时间越长，颜色越接近清新绿色；较短的弧更深。
- 圆环目标可在设置中修改；超过目标后圆环保持闭合，工时继续累计至当日最多 `24:00:00`，次日自动继续累计。此上限同时应用于实时计时、存档和每日显示；旧版已有的超限日期会归一到 24 小时，日期与其他记录保留。
- 默认每周以周一开始，也可在设置中从七天里任选起始日。左侧是**这一行连续七天的总工时**，包含月初、月末跨月日期。周末颜色始终对应实际的周六、周日。月累计仅统计正在查看的月份。
- 小时汇总显示到小数点后一位；详细记录和计时器保留到秒。周、月汇总按每天实际保存的时长相加，可以超过 24 小时。
- 关闭或最小化日历，工作球继续计时。
- **工作状态下，锁屏、睡眠时间也计入工时**。「临时离开」停止累计，显示暖橙红色的「已暂停」，直到选择继续工作；暂停跨午夜也不会增加工时。
- 正常退出时会询问退出期间是否继续计时。选「继续计时并退出」会完全关闭程序，下次启动补计退出期间的工时，包括关机时间；选「停止计时并退出」会签退并保留已有记录。暂停时可选从退出时刻开始计时，或保持暂停。取消为默认选项，下班状态直接退出。
- 程序运行中遇到 Windows 关机、重启或注销，工作和暂停中的会话都会自动下班并保存。已选择续计退出后，程序无法感知之后的关机，因此这段时间也会补计。
- 异常中断后重启，工作在最后成功保存的计时点结束，不会补算关机或未运行期间的时间。自动保存间隔为 15 秒，因此最近尚未保存的工时可能丢失；恢复后需要手动签到继续工作。暂停状态下异常中断不会增加工时。

## 每日记录

月累计与每日记录分开显示，日历顶部的月度卡片只统计正在查看的自然月。

点击日期可查看精确到秒的上班、休息、继续工作、下班时间，以及对应的在岗与休息时段。今日尚未结束的时段显示到「现在」，记录随计时更新。跨午夜时段分在两天显示，次日标注「从前一天延续」；休息时段不计入累计工时。

自动下班会注明原因：退出程序、Windows 关机／重启／注销，或异常中断后按最后保存时间结束。补录和总时长修正也留下操作时间与修改前后的累计；修改过去日期时，记录显示实际调整日期。

1.5.0 以前保存的累计工时继续保留，未记录的历史节点无法还原。手动调整只改变累计工时，不改写已记录的在岗与休息时段；旧版数据、补录和每日 24 小时上限都可能使累计与时段相加结果不同。

## 本地数据

默认不需要联网。开启「手机查看」后，会向自己配置的服务器同步当前状态；本机计时不依赖同步成功。字体已随应用内置，不依赖在线字体服务。

工时默认存于 Windows 的 `%APPDATA%/拾光/worklog.json`，也可右键工作球选择「打开数据文件夹」。累计工时和操作明细保存在同一个文件中。活跃计时每 15 秒保存一次，签到、暂停、继续工作、签退、补录、休眠及退出时立即保存；另保留一份最近的有效备份 `worklog.json.bak`。

在「设置 → 高级」中可选择新数据文件夹。已有记录会复制到新位置并立即切换，原文件保留。新文件夹不能已有拾光记录，以免覆盖历史。迁移后若数据磁盘不可用，启动时会提示连接磁盘，不会创建空历史覆盖旧记录。也可以用「导出备份」另存所有日期的工时。

偏好设置始终存于 `%APPDATA%/拾光/settings.json`，其中记录数据文件夹的位置。

## 补录与设置

- **补充时长**：在该日现有工时上增加输入的时长。
- **修正总时长**：把该日累计调整为输入值；设置为零可清除该日的进度环。
- 补录可精确到秒，只能选择今天或过去的日期。超过 24 小时会直接提示并禁用保存；24 小时只能搭配 0 分 0 秒。今日正在计时时，补录后继续累计，达到 `24:00:00` 后当日不再增长，次日照常计时。
- **常规**：开机自启动、简体中文／English、每周起始日、薄荷晴空／雾蓝石墨／松石暖砂三套主题。
- **工时**：设置圆环转满一圈对应的时长，范围为 1 分钟至 24 小时。修改后所有月份按新目标显示，不改变原工时。
- **快捷键**：为上班、休息、继续工作、下班和显示／隐藏工作球设置全局按键组合。
- **高级**：查看程序安装位置、迁移数据文件夹、打开文件夹、导出备份。

新安装默认启用 Windows 登录自启动，可随时在设置中关闭，已有设置会保留。自动启动只显示工作球，不会自动签到。安装版的启动项指向安装目录的程序；免安装版指向原始 EXE，不使用临时解压目录。移动免安装程序后，手动运行一次即可更新启动路径。开发模式与界面测试不会更改正式启动项；专门的启动项测试使用独立注册表项并在结束时清理。

若 Windows 曾暂停此项，请在常规设置中关闭后重新开启，或在 Windows“启动应用”中恢复。若保留免安装版与安装版，请固定使用其中一份，避免交替运行时来回改写启动路径。同一台电脑只允许一个正式应用实例；同账户重复打开会回到已有应用，另一个 Windows 会话中的重复启动会直接退出。

## 月度目标与手机查看

在「设置 → 月度目标」调整基础门槛和基础档月收入，并添加或删除多个 Bonus 档，为每一档分别设置工时门槛和月收入。默认基础为 160 小时 / CNY 800，另有一档 Bonus 为 200 小时 / CNY 1600。各档金额都是当月预计总收入，不叠加。工时支持 1–744 小时、最多两位小数，金额支持非负数和两位小数；每个 Bonus 的工时门槛必须高于前一档，金额不能低于前一档。关闭 Bonus 会保留各档设置，只使用基础目标；删除全部 Bonus 后也只使用基础目标。已有的单 Bonus 设置会自动保留为第一档。

日历和手机页面显示所有启用的档位，进度、剩余工时和预计收入指向下一未达成档位；全部达成后显示最高档。例如设置基础 160 小时 / CNY 800、Bonus 1 为 200 小时 / CNY 1600、Bonus 2 为 240 小时 / CNY 2200，累计到 200 小时后，下一目标就是 240 小时 / CNY 2200。

目标按本机自然月重新累计，不受每周开始日影响。达到目标后仍会继续记录工时。补录、修正以及退出后补计会更新月进度。庆祝窗口每月每档自动出现一次，重启或将工时改低再改高不会重复提醒；一次跨过多档只庆祝最高已达成档位。已有的基础档与 Bonus 庆祝记录继续保留。可以关闭自动庆祝，或使用「预览已保存的庆祝效果」查看礼花，预览不改变记录与提醒历史。

「设置 → 手机查看」填写自己的 HTTPS 查看网址和电脑连接密钥，打开同步后保存。手机通过浏览器打开网址，用独立的查看密码登录。电脑密钥与手机密码用途不同，已经保存的电脑密钥留空即可沿用。密钥使用 Windows 凭据加密，不会显示回页面。

电脑约每 5 秒同步今日累计、当前模式、月累计与目标；网页每秒显示计时，断网或退出后最多约 20 秒显示离线并停止推算。网页不提供打卡、修改或控制电脑功能。关闭同步不影响本地计时，云端保留最后同步的快照。完整每日明细、文件路径、连接密钥不出现在查看接口中。部署与改密说明见 [云端服务](../cloud/README.md)。

## 全局快捷键设置

在「设置 → 快捷键」中，点击对应动作的录入框，再按下希望使用的组合键，最后点击保存。五个动作默认均未设置；清除某项并保存可禁用该动作。保存的快捷键在使用其他应用时也能触发，重新打开拾光后自动注册。

使用 Ctrl 或 Alt 搭配字母、数字或导航键，可再加入 Shift；也可单独使用 F1–F24。不支持 Windows 键。按 Esc 取消录入，录入期间已设置的快捷键会暂时停用，避免触发工作状态变化。

| 动作 | 效果 |
| --- | --- |
| 上班 | 从下班状态开始工作计时。 |
| 休息 | 工作中暂停累计工时。 |
| 恢复工作 | 从休息状态恢复计时。 |
| 下班 | 结束当前工作或休息会话。 |
| 隐藏或显示悬浮球 | 切换球体可见性，不改变计时状态。 |

动作与当前状态不符时不会重复记录，例如已上班时再次按上班快捷键，不会产生新的签到节点。

保存前会检查多个动作是否使用相同组合，并向 Windows 尝试注册。若组合被其他应用占用、由系统保留或无法注册，界面会提示，原有绑定继续使用。拾光无法识别占用组合的具体应用；改用其他按键组合即可。

启动时也会重新检查注册结果。如果已保存的组合不可用，「快捷键」页会显示提示，其他成功注册的动作仍可使用。可以更换组合，或待其释放后点击「重新检查」，确认可用后再保存。

## 卸载与数据选择

普通卸载会先移除程序、快捷方式和启动项，然后询问是否删除当前工时记录、设置和缓存，默认选择“否”。选择“是”会删除默认数据目录，以及当前自定义数据目录中的 `worklog.json`、`.bak` 和 `.tmp`，不会删除自定义目录本身、其他文件、导出的备份或之前迁移留下的旧副本。删除无法撤销。

覆盖升级和静默卸载不会询问或删除工时。若你打算换盘重装，请保留数据，再在安装向导选择新的程序目录。

若主记录损坏，应用尝试读取备份；两份均损坏时会提示错误，避免悄悄清空历史。移动免安装程序的位置不会影响记录。

仓库 [界面预览](images/calendar-preview.png) 使用隔离测试目录中的**示例工时**，不会写入真实工时。

## 换电脑与恢复备份

1. 在原电脑的“设置 → 高级”导出工时备份，退出拾光。
2. 在新电脑安装并运行一次拾光，确认数据目录，然后退出。
3. 将新电脑现有的 `worklog.json` 和 `worklog.json.bak` 另存备份，再将导出的 JSON 复制为数据目录下的 `worklog.json`；同步复制一份为 `worklog.json.bak`。
4. 重启拾光，检查日期、累计时长和已有明细。备份中的未结束时段会在导出时闭合，恢复后从签退状态开始；导出不会改变当前工作球的状态。

不要直接跨电脑复制旧的 `settings.json`，其中的数据目录可能是原电脑专用路径。目标、主题和开机启动可在新电脑重新设置。手机查看只同步最新只读状态，不能用来恢复完整历史；当前没有界面内导入功能。

## 开发

```powershell
npm ci
npm start
npm test
npm run test:startup
npm run test:shutdown
npm run test:exit
npm run test:monthly
npm run test:cloud
npm run test:phone
npm run test:shortcuts
npm run test:system
npm run test:ui
npm run check:docs
npm run dist
npm run release:prepare
```

- `src/main.cjs`：桌面窗口、托盘、进程生命周期与 IPC。
- `src/clock.cjs`：按本机日期拆分时间、累计工时、操作节点和每日明细。
- `src/lifecycle.cjs`：保存退出选择并恢复一次续计，保存失败时保留原工作状态。
- `src/shortcuts.cjs`：全局快捷键校验、注册与冲突恢复。
- `src/store.cjs`：本地原子写入和备份恢复。
- `src/renderer/`：悬浮球、月历和界面样式。
- `tests/`：计时、存档、退出保存和真实 Electron 窗口的集成检查；`test:shutdown` 仅向隔离测试进程发送会话结束消息，不会关闭 Windows。

使用 Electron 与原生 HTML / CSS / JavaScript。窗口启用了上下文隔离、渲染器沙箱和有限的预加载接口；不加载外部页面。

辅助文字使用内置的 Noto Sans SC；月份和日期使用 Nunito，品牌与主标题保留站酷快乐体。字体均采用 SIL Open Font License，许可证随 `assets` 分发。Noto Sans SC 来自 [Google Fonts 的字体仓库](https://github.com/google/fonts/tree/main/ofl/notosanssc)。
